# 指标口径

本文件提供通用经营分析的默认核验方法。用户提供的正式制度、财务口径或经批准模板优先级更高；发生冲突时记录差异并请求确认，不静默覆盖。

## 证据优先级

1. 用户提供的正式制度、会计政策、指标字典或监管口径。
2. 已批准并标明期间与范围的财务报告、经营月报或董事会材料。
3. 原始系统导出、Excel 明细和经过核对的台账。
4. 可由上述数据按明确公式计算的派生指标。
5. 口头说明和未标明来源的二手材料只能作为待确认线索。

## 每个指标必须记录

| 字段 | 要求 |
| --- | --- |
| 指标名称 | 使用正式名称，避免同义词混用。 |
| 本期与对比期 | 写明年月、季度或累计区间。 |
| 组织范围 | 写明集团、板块、公司、航线、区域或项目。 |
| 单位与币种 | 金额、数量、百分比、百分点和汇率分别标明。 |
| 来源 | 填写实际文件、系统或责任部门，不自动补造。 |
| 计算式 | 派生值写清分子、分母和异常分支。 |
| 口径备注 | 记录并表范围、一次性项目、重分类和估算。 |

## 通用计算规则

- 同比增长率：`(本期 - 上年同期) / abs(上年同期)`。上年同期为 0、跨越正负或口径变化时标记“不适用”，直接展示差额并解释原因。
- 环比增长率：`(本期 - 上期) / abs(上期)`。季节性明显的指标不得只凭环比下结论。
- 完成率：`实际值 / 目标值`。目标值为 0 或目标方向为“越低越好”时使用制度定义，不套用普通公式。
- 利润率：`利润 / 营业收入`。必须注明使用毛利、营业利润、利润总额还是归母净利润。
- 资产收益指标：明确分子期间、分母使用期末值还是平均值，不混用 ROA、ROE 与投入资本回报率。
- 单位成本：`成本 / 对应业务量`。分子与分母必须覆盖同一期间、组织和业务范围。
- 百分点变化：`本期比率 - 对比期比率`，单位写“个百分点”；不得写成百分比增长率。
- 贡献度：只有总量能够完整分解且没有交叉重复时计算；必须说明分母和是否含抵消项。

## 航运与物流类指标检查

以下仅列核验维度，不预设公司正式公式：

- 运量、箱量、周转量：核对自然箱/标准箱、重箱/空箱、完成量/承运量和是否含内贸。
- 运价与单箱收入：核对币种、燃油附加费、滞期费、代理收入和内部结算是否纳入。
- 船舶效率：核对自有/租入、营运天/日历天、在航/在港、空驶和停航口径。
- 准班率与服务质量：核对统计航线、样本量、延误阈值和港到港/门到门定义。
- 燃油与碳排：核对燃油种类、航次边界、排放因子、吨海里或箱海里分母以及监管范围。
- 物流业务量：核对海运、铁路、公路、仓储和代理业务是否重复计数。

## 表达纪律

- 报告展示值可按统一精度四舍五入，计算必须使用未四舍五入原值。
- 同一页面保持同一币种与数量级；换算汇率必须写明日期或期间。
- “增长”“改善”“下降”“恶化”要结合指标方向判断，不能只根据正负号。
- 原因分析必须有材料证据。只有时间上的同时变化不能证明因果关系。
- 预测、预算和管理目标必须与实际值明显区分，并注明版本与批准日期。
