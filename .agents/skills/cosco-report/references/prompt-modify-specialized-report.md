# 修改特化报告提示词

特化报告的主维护入口是 `report-packages/<report-id>/report-package.json`，不是生成后的 HTML 或 `document.json`。

```text
使用 $cosco-report 修改当前仓库中的特化报告。

目标报告包：
report-packages/[报告 ID]/report-package.json

修改范围：
- 页码、页面 ID 或页面标题：[待填]
- 元素 ID、图表标题或可见文字：[待填]
- 只修改：[待填]

当前问题：
1. [可观察问题]
2. [可观察问题]

期望结果：
1. [具体的内容、位置、尺寸、图表或图片要求]
2. [用户最终应能如何继续编辑]

必须保持：
- 其他页面、现有文字数据和公司主题不变，除非上文明确要求。
- 每张图表和表格继续独立维护数据，不新增集中数源、公式、绑定或勾稽。
- 继续使用稳定页面、元素、系列和类目 ID。
- 不直接修改 artifacts/*.html、dist/index.html 或编译后的 document.json。
- 不把脱敏占位数据替换为猜测的真实数据。

验收标准：
- 运行报告包 validate、compile 和 build。
- 检查页内文字编辑、当前图表/表格的局部数据编辑、图表隔离、标签位置和刷新保存。
- 重新生成 PDF 并逐页检查重叠、裁切、异常留白、来源行和页脚。
- 交付时列出修改的源文件，不要只报告生成产物。
```
