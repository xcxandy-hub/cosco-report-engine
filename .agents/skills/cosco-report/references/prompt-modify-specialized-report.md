# 修改特化报告提示词

特化报告的主维护入口是 `report-packages/<report-id>/report-package.json`，不是生成后的 HTML 或 `document.json`。

```text
使用 $cosco-report 修改当前仓库中的特化报告。

目标报告包：
report-packages/[报告 ID]/report-package.json

先读取并锁定现有 `authoringMode`：
- `independent`：保持每张图表和表格各自持有数据，禁止新增集中数据源、公式、绑定、勾稽或跨组件关联。
- `bound`：保持既有 fields / derived / rules / bindings 及稳定 ID，不得为了套用新模板擅自改成 independent；绑定事实继续由报告包和本地数据拥有。

修改范围：
- 页码、页面 ID 或页面标题：[待填]
- 元素 ID、图表标题或可见文字：[待填]
- 只修改：[待填]

当前问题：
1. [可观察问题]
2. [可观察问题]

模板相关（如适用）：
- 当前封面模板 / 目标封面模板：[待填]
- 当前页眉页脚 / 目标页眉页脚：[待填]
- 必须保留的人工标题、图片、Logo 位置或规则线：[待填]

期望结果：
1. [具体的内容、位置、尺寸、图表或图片要求]
2. [用户最终应能如何继续编辑]

如修改图表或表格，必须同时写清：
- 初始行列数量、类目/指标名、系列/字段名：[待填]
- 各列格式、单位与脱敏示例值：[待填]
- 是否需要增删行列，以及非法值的可观察提示：[待填]

必须保持：
- 其他页面、现有文字数据和公司主题不变，除非上文明确要求。
- 数据所有权必须遵守上面锁定的 `authoringMode`，不得在修改中偷换模式。
- 数据组件打开后继续显示可逐格修改的单元格网格，不改成原始 TSV 文本框。
- 继续使用稳定页面、元素、系列和类目 ID。
- 不直接修改 artifacts/*.html、dist/index.html 或编译后的 document.json。
- 模板变更继续输出普通元素；切换页眉页脚不得删除正文、图表或表格，横竖坐标不得串用。
- 不把脱敏占位数据替换为猜测的真实数据。

验收标准：
- 运行报告包 validate、compile 和 build。
- 检查页内文字编辑、当前图表/表格的单元格编辑、Excel 连续区域粘贴、图表隔离、标签位置和刷新保存。
- 重新生成 PDF 并逐页检查重叠、裁切、异常留白、来源行和页脚。
- 交付时列出修改的源文件，不要只报告生成产物。
```
