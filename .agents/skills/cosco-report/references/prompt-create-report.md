# 新建特化报告提示词

把下列模板与脱敏文字稿、图表数据和本地图片一起交给智能体。页数填范围，不写死上限。

```text
使用 $cosco-report，在当前 COSCO Report Engine 仓库中制作一个本地离线、可继续编辑的特化 PDF 报告生成器。

报告任务：
- 报告名称：[待填]
- 核心问题：[待填]
- 目标读者：[待填]
- 报告期间及组织范围：[待填]
- 预计页数：约 [待填] 至 [待填] 页，由内容决定，不设硬上限
- 页面方向：横版 / 竖版 / 混排
- 密级及免责文字：[待填]

内容结构：
1. 模块一：[名称]
   - 需要回答的问题：[待填]
   - 子模块：[待填]
   - 必须表达的结论：[待填]
   - 图表、表格、图片要求：[待填]
2. 模块二：[按需继续]

每个数据组件都要逐项填写，不得只写“放一张图”或“放一个表”：
- 组件名称与所在页面：[待填]
- 类型：折线 / 柱状 / 柱线组合 / 环形 / 表格
- 初始网格：共 [待填] 行、[待填] 列
- 第一列的类目或指标名称：[逐项列出]
- 后续系列或字段名：[逐项列出]
- 每列数据格式与单位：[整数 / 小数位数 / 百分比 / 币种 / 文本；单位待填]
- 脱敏示例值：[文字和表格文本可用星号；图表序列必须给有限数值，可用 0 或明确标注的合成数字；不得放真实数据]
- 用户是否需要频繁增删行列：[待填；independent 默认允许]
- 校验要求：[非空、非负、至少一个正值或其他明确规则]

视觉方向：
- 整体风格与信息密度：[待填]
- 公司特色、Logo、色调和字体：[待填]
- 封面模板：[电影全幅 / 编辑刊号 / 机构侧轨 / 分栏影像 / 出版视窗 / 自定义变体]
- 封面图片、蒙版方向、标题/副标题位置和期次信息要求：[待填]
- 内容页页眉页脚：[细线页眉 / 品牌侧轨 / 编辑页角 / 自定义变体]
- Logo 位置、规则线、章节名、密级和页码要求：[待填]
- 章节图和电影感蒙版要求：[待填]
- 必须保留的参考设计：[待填]
- 不希望出现的风格：[待填]

固定边界：
- 只处理脱敏材料，不编造数字、来源、原因或管理结论。
- 新报告使用 authoringMode: "independent"。
- 每张图表和表格独立保存自己的数据，不建立集中数据源、公式、勾稽或跨组件关联。
- 文字可页内直接修改；图片可拖动、滚轮缩放和裁切；图表和表格在组件旁打开按上述规格预建的单元格网格，可逐格修改、增删行列和粘贴 Excel 连续区域；图表标签在组件旁调整。
- 模板只能生成普通元素；封面图、蒙版、Logo、标题、副标题、页眉、页脚、规则线和页码都必须允许我继续选中微调。横版和竖版分别排版，不能机械缩放。
- 不引入 CDN、运行时网络请求、遥测、登录或云上传。

第一阶段只输出：输入盘点、待确认项、不超过五条设计观、模块到页面映射、逐页规划表、图表清单、图片清单和建议页数，暂不修改代码。

我确认方案后再实施，并执行 validate、compile、build、真实浏览器交互检查和最终 PDF 逐页渲染检查。
```
