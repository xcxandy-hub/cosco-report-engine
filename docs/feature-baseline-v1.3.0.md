# Local Report Studio v1.3.0 特性基线

状态：`frozen-baseline`  
应用版本：`1.3.0`  
工程格式：`ReportDocument 1.3`  
固化日期：`2026-08-15`

本文是 v1.3.0 的功能边界。它说明这个版本已经交付、可以验收的能力，也明确未承诺的能力。规范性行为以 [v1.3.0 契约](./contracts-v1.3.0.md) 为准，机器可读版本与产物哈希位于 [`release/v1.3.0.json`](../release/v1.3.0.json)。

## 1. 产品定位

Local Report Studio 是面向经营分析、财务简报、专题研究和管理层汇报的本地固定版位报告编辑器。它以 A4 和毫米坐标为基础，使用同一套报告组件生成编辑态与打印态，最终交付为可离线打开的单 HTML。

v1.3.0 的产品边界是：

- 数据与图片留在本机，无登录、上传、遥测或远程模板请求。
- 报告页面是固定版位，不是 Word 式连续长文流。
- 编辑器负责设计、数据录入、检查和浏览器打印，不直接生成 PDF 字节流。
- `ReportDocument` 是结构事实源；图片二进制独立存储，选择框、参考线和缩放不进入工程 JSON。

## 3. 关键交互基线

### 3.1 选择与几何

- 单击选择元素；`Shift`、`Ctrl` 或 `Command` 单击增减选择。
- 在空白画布拖动进行框选。
- 拖动元素移动；八个控制点调整四边和四角。
- 方向键移动 1 mm；`Shift + 方向键` 移动 5 mm。
- `Ctrl/Command + A` 全选当前页，`Ctrl/Command + D` 复制，`Delete/Backspace` 删除。
- 被锁定元素不参与移动、缩放、对齐、分布或删除。

### 3.2 对齐与吸附

- 单选元素执行左/中/右或上/中/下对齐时，以完整页面为基准。
- 多选元素执行同一命令时，以当前可移动、可见选区的包围盒为基准。
- 三项以上可执行水平或垂直等间距分布，首尾元素保持包围盒边界。
- 拖动和缩放吸附比较左/中/右、上/中/下特征线。
- 候选线包括页面边缘、页面中心、页边距、网格和其他可见元素。
- 命中阈值为屏幕空间 8 px；按住 `Alt` 临时关闭吸附。

### 3.3 页内文本编辑

- 双击标题、正文、结论、来源行、KPI 标签/数值/单位/说明、表格标题、表头、单元格以及页眉页脚文字进入编辑。
- 多行字段使用原生 `textarea`，单行字段使用原生 `input`；不使用 `contenteditable`。
- 中文输入法组合期间不提交、不触发编辑器快捷键。
- 粘贴只接受纯文本；`Esc` 取消整个会话，`Tab` 提交并跳到下一个字段。
- 一次页内编辑会话只形成一条全局撤销记录。
- 图表内部文字与数字通过右侧数据面板修改，不在 SVG 上直接编辑。

### 3.4 页面背景与内容图片

- 点击页面缩略图或画布空白处进入“页面”检查器。
- 封面、标准、数据、空白和尾页使用整页背景槽；章节页使用顶部 70 mm 槽。
- 背景支持替换、移除、焦点、叠色、混合、调色和暗角。
- 页面背景不进入图层、不参与吸附且不能直接拖动缩放；焦点和图片风格在页面检查器修改。
- 内容图片是普通元素，可自由移动、缩放、裁切并进入图层。
- 背景与内容图片可以双向转换，转换是可撤销文档事务。

### 3.5 缩放

- 工具栏和 `Ctrl/Command + 滚轮` 均支持 50%-200% 缩放，步进为 5%。
- 滚轮缩放以鼠标下方的页面 mm 点为锚点，并在布局后补偿滚动位置。
- 缩放只改变编辑投影，不修改任何报告几何或打印结果。
- 浏览器滚动边界和设备像素取整可能造成小于约 1 px 的瞬时视口抖动；它不是文档坐标损失，也不会逐次改写报告元素。

## 4. 页面与元素基线

### 4.1 页面类型

| 类型 | 默认制度元素 | 背景槽 |
| --- | --- | --- |
| `cover` | 无自动页眉页脚 | 整页 |
| `section` | 可编辑页眉、页脚、页码和规则线 | 顶部 70 mm |
| `standard` | 可编辑页眉、页脚、页码和规则线 | 整页 |
| `data` | 可编辑页眉、页脚、页码和规则线 | 整页 |
| `blank` | 无自动页眉页脚 | 整页 |
| `backcover` | 机构、免责声明、联系方式、密级均为可编辑元素 | 整页 |

### 4.2 图表类型

- `line-chart`：趋势展示，默认只标末端点。
- `bar-chart`：分类和系列比较，默认显示柱顶标签。
- `combo-chart`：每个系列独立选择柱/线、左/右轴和单位。
- `donut-chart`：构成展示，显示类别与占比。

图表统一使用 SVG renderer；打印前关闭动画、重设 option 并同步 resize。

## 5. 工程与兼容性基线

- 应用版本是 `1.3.0`，文档 schema 是 `1.3`，二者不是同一个版本号维度。
- 读取支持 `1.0`、`1.1`、`1.2` 和 `1.3`；归一化与导出结果固定为 `1.3`。
- 1.0-1.2 工程在缺少角色元素时补入可编辑页眉、页脚、页码、规则线或尾页制度文字。
- 旧 `element.image` Data URL 迁移为 `assetId` 与资产记录。
- 旧字符串 `content` 迁移为单个文本 run；工程不持久化 HTML。
- 不提供 1.3 向旧版本的降级导出。

## 6. 质量门禁

固化版本必须通过：

```bash
npm run typecheck
npm run build
npm run check:offline
npm run check:contract
npm run qa:visual
```

`npm run verify:release` 顺序执行全部门禁。视觉 QA 必须另外目检 contact sheet，脚本成功不能代替人眼确认溢出、碰撞、对比度和图片裁切。

## 7. 明确不在 v1.3.0 范围内

- 元素旋转。
- 持久化组合/拆分；当前只有多选和选区整体操作。
- 自定义标尺、用户拖出的永久参考线和画布平移工具。
- 长文自动续页、跨页长表、脚注、孤行寡行控制。
- PPTX、DOCX 或 PDF 字节级导入与导出。
- 任意 HTML 富文本、自由 CSS、自由字号和自由元素颜色。
- 网络模板库、远程数据源、多人协作、账户、云存储和遥测。
- 直接连接 Excel 应用；当前通过剪贴板 TSV 交换数据。
- 跨浏览器像素级完全一致；打印仍受本机字体和浏览器打印引擎影响。

上述条目不是隐藏功能或未记录的缺陷。任何一项进入产品范围，都必须更新应用版本、特性基线、契约和验收用例。

## 8. 已知限制

- 浏览器站点数据被清除后，自动保存和 IndexedDB 图片会丢失；重要工程必须导出 `.report.zip`。
- 缺少主题首选字体时，排版可能发生替换，应用会在打印检查中提示。
- 背景图是页面属性而不是普通图层；需要自由移动时必须先转为图片元素。
- 原生浏览器打印对“背景图形”、缩放比例和页边距有用户侧设置要求。
- 50 MB 是工程图片预算告警线，不是硬性导入上限。
