# 在线 PDF / 报告编辑器调研 v1.4

调研日期：2026-08-15。本文只记录官方产品页能够验证的公开能力，不推断私有技术栈，也不把营销措辞当成可复现性能证据。

## 调研对象

| 产品 | 已核验官方页面 | 主要观察 |
| --- | --- | --- |
| Canva | [Report maker](https://www.canva.com/create/reports/) | 模板是进入编辑的起点；插入后仍可编辑文字、图表、图片和品牌样式。强调模板、拖放、图表、品牌资产与高质量 PDF。 |
| Adobe Express | [Why choose Adobe Express](https://www.adobe.com/express/why-choose-express) | 强调模板、品牌套件、快速调整尺寸、协作和输出；品牌字体、颜色与标志被集中管理。 |
| Piktochart | [Piktochart](https://piktochart.com/) | 报告、信息图和演示共用可视化编辑模式，强调图表、品牌化和从模板快速进入内容制作。 |
| Visme | [Canva vs Adobe Express](https://visme.co/blog/canva-vs-adobe-express/) | 产品比较页集中展示品牌控制、数据可视化、内容块和输出能力，可用于观察成熟产品如何解释复杂编辑能力。 |

## 共性经验

1. 模板与元素不是同一个层级。模板负责快速起步，落到画布后应成为可修改的对象，而不是黑盒组件。
2. 品牌约束应集中管理。字体、颜色、标志和图表色需要由主题或品牌套件控制，不能散落为任意局部值。
3. 高频排版依赖网格、吸附、裁切、对齐、复用块和图层，而不是依赖更多装饰组件。
4. 成熟产品保留便利入口，但不会要求用户理解内部数据结构；“KPI”可以是入口名称，持久化时仍可由文本和色块组成。
5. 输出质量是产品能力的一部分。编辑预览、PDF 打印、图片清晰度、字体和背景必须进入同一验收链。

## v1.4 采用

| 调研经验 | v1.4 落点 |
| --- | --- |
| 模板插入后元素化 | 组件面板分为“基础元素”和“组合模块”；KPI、引述、带标题图表/表格插入后生成基础元素。 |
| 可复用块 | 一层 `groupId/groupName/presetId/presetSlot` 记录组合，不新增 KPI 等持久化类型。 |
| 品牌约束 | 延续主题 token、字体槽、字号白名单和语义色；新增“出版中性”“海运出版”两个非机构品牌主题。 |
| 对齐与精确布局 | 延续 mm 坐标、屏幕空间吸附、六向对齐和等间距分布。 |
| 编辑自由与可恢复 | 组合整体移动、复制、删除、锁定、隐藏；拆组后逐元素编辑；全部进入撤销历史。 |
| 高质量 PDF | 继续复用 DOM 文字、ECharts SVG、命名 `@page` 与逐页 PNG 视觉门禁。 |

## 未采用

- 不加入账号、云协作、在线模板库或运行时外部素材，因为会改变本地机密数据边界。
- 不加入 AI 生成内容或自动补造来源；报告判断和来源必须由用户材料支撑。
- 不复制任何网站的专有模板、品牌外观或交互代码。
- 不在 1.4.0 做组合比例缩放。文字组合的任意比例缩放会与字号、行高白名单冲突，需要单独设计响应式布局规则。

## 独立判断

“组件越少越元素化”也不是目标。图表和表格仍保留为基础元素，因为它们拥有结构化数据、专用渲染和属性面板；若把图表拆成线、点和文字，会破坏数据绑定、打印冻结和可维护性。元素化边界应按“是否具有独立数据与渲染语义”决定，而不是只按视觉上能否拆开决定。
