## 下一阶段优先级

1. 先补期间生命周期与多口径快照，因为它们决定每月复用成本。
2. 再补单位存储/展示转换与旧规则并集，降低人为换算和勾稽遗漏。
3. 风险阈值和外汇序列只在正式制度和数据来源明确后加入，不从旧界面文案猜公式。
4. 页面启停/排序属于报告包配置，不回到通用编辑器里做 PPT 式自由编排。
