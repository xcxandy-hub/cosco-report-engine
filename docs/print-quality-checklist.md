# 打印检查清单 v2

本清单把报告检查分成“模型静态规则”和“渲染后检查”两级。静态规则可由应用在打印前确定性执行；渲染后检查必须基于实际 PNG/PDF，不用源码或编辑器预览代替。

## 一级：模型静态规则

| 规则 | 阈值或判定 | 处理方式 | 对应计划 |
| --- | --- | --- | --- |
| 页面边界 | 任一元素超出 A4 页面即失败 | 指明页码与元素名 | R13 |
| 制度安全边距 | 普通内容距页面边缘小于 12.7 mm 时提示；明确的全幅母版图片除外 | 提示移入版心或确认全幅设计 | R13 / D2 |
| 内容块间距 | 可见元素包围盒之间小于 7.6 mm 时提示；同一 `groupId` 内部、表格内部和有意叠放的背景元素除外 | 列出发生拥挤的元素对 | R13 / D2 |
| 来源行 | 页面存在图表或表格但没有 `semanticRole: source` 的显式文本即提示 | 只提示，不自动生成来源 | R13 |
| 表格溢出 | 估算内容高度大于元素高度即提示，并给出建议拆分行 | 不缩小到白名单以下 | R13 |
| 字号 | 元素字号不在 8/10/12/14/28 pt 白名单即失败 | 迁移时吸附到最近档位 | R9 / R13 |
| 图表标签 | 统计明确关闭标签的图表数量 | 在检查结果中列出 | R13 |
| 字体 | `document.fonts.check()` 未找到使用字体槽的首选字体 | 标记“字体替换风险” | R3 |
| 母版图 | cover/section/backcover 没有图片 | 作为有意的版式质量提示 | R5 / R6 / R13 |
| 压图可读性 | 页面或内容图上有文字，但图片没有叠色层 | 要求启用主题化叠色层 | R18 |
| 图片清晰度 | 按最终显示尺寸计算低于 150 DPI | 标记“打印可能发虚” | R21 |
| 工程体积 | 图片资产总量大于 50 MB | 显示持续体积告警 | R21 |
| 未使用资产 | 引用次数为 0 | 提示清理，不自动删除 | R21 |
| 占位符 | 文本匹配 `xxx`、`lorem`、`ipsum`、`TODO`、`[insert` 等模式 | 打印前提示逐项确认 | D2 |

静态间距规则不把页眉、页脚、母版图、选择框、参考线或裁切衬底当作文档内容。重叠检测必须允许明确的层叠设计，例如文字位于带遮罩的母版图上；这类可读性由压图规则单独检查。

## 二级：渲染后检查

每次有意义的版式修改后运行：

```bash
npm run qa:visual
```

脚本输出逐页 PNG、合成 contact sheet 和中间 PDF。检查顺序固定如下：

1. 文字是否被容器或页面边界裁掉；长标题、中文标点、英文长词和数字单位优先。
2. 是否存在文字穿过图形、线条穿字、元素无意堆叠、图表标签相撞。
3. 来源行、页脚和正文是否碰撞；页码、密级和尾页制度区是否完整。
4. 内容块间视觉间距是否小于 7.6 mm，页面安全边距是否小于 12.7 mm。
5. 同类列、卡片、表格边线和图表绘图区是否对齐。
6. 文字与图标对背景是否有足够对比；压图文字是否始终落在叠色层上。
7. 图片是否模糊、像素化、裁切主体丢失或焦点错误。
8. 是否残留模板占位符、空图表、空来源行或调试叠层。
9. 纵横混排的页面尺寸、页眉页脚和分页顺序是否正确。

发现问题后只修改有缺陷的页面，但最终交付前仍要重跑完整 contact sheet。文本抽取和静态检查可以证明结构，不能代替视觉检查。

## 研究依据

- OpenAI PDF skill：先渲染，再逐页检查对齐、间距、清晰度，修正后重新渲染。
- OpenAI Codex Skills 官方文档：把确定性、易出错的流程放进脚本，让说明保持简洁并按需加载。
- Anthropic PPTX skill：建议最小 0.5 英寸页边距、0.3–0.5 英寸内容间距，并要求检查溢出、重叠、来源/页脚碰撞、低对比和占位符残留。本文只学习检查方法与阈值，没有复制其实现代码。
