## 共同设计语法

1. 页面角色先于组件：封面、导读、章节、叙事页、数据页和尾页承担不同任务。
2. 每页只回答一个主要问题，标题直接表达信息，不使用空泛的“数据分析”“核心洞察”。
3. 数字层级由字号、位置、字重、单位和说明共同建立；背景框只是可选容器。
4. 图表标题、图表主体、来源行是相邻但独立的对象，便于分别编辑和复用。
5. 长报告需要节奏变化；短报告需要结论密度。编辑式、平衡式和图谱式页面可以在同一报告共存。
6. 来源、页码、密级、免责声明和图表注释不是装饰，必须稳定、可核验、可打印。
7. 专业感来自约束一致性，而不是复制机构标志、专有色或摄影风格。

## v1.4 产品落点

| 学习结论 | 实现 |
| --- | --- |
| KPI 是组合，不是独立数据类型 | `box + 4 text`，分别承担背景、标签、数值、单位和变化；语义角色保留数字体与来源检查等规则。 |
| 图题与图分离 | 图表/表格模块由 caption text 加 chart/table 构成，拆组后可单独编辑。 |
| 来源是语义而不是视觉类型 | 来源统一为 `text`，通过 `semanticRole: "source"` 参与打印检查。 |
| 图表类型共享数据模型 | 统一 `type: "chart"`，以 `chartKind` 切换 line/bar/combo/donut。 |
| 长报告需要出版入口 | 新增六页“研究出版”模板：封面、导读、章节、核心洞察、数据图谱、尾页。 |
| 版式不应复制机构品牌 | 新增“出版中性”“海运出版”主题，颜色和字体角色为本项目自有 token。 |
| 密集页必须稳定 | 数据图谱模板固定标题、表格、来源和制度区；仍使用 mm 坐标与打印检查。 |

## 没有从样本推出的结论

- 样本展示的是各机构针对特定内容的成品，不证明同一版式适用于所有经营报告。
- 样本中的摄影、品牌字体、标志和专有色不属于本项目可复制资产。
- 单份报告的视觉效果不能证明其在线编辑器、协作流程或内部数据模型。
- 173 页出版物的连续长文、目录自动生成和跨页表格仍超出固定版位编辑器 1.4.0 的范围。
