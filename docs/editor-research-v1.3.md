# Local Report Studio v1.3 编辑器交互调研

调研日期：2026-08-15。本文只把官方帮助页中可以直接核验的行为记为“已验证”，其余内容明确标为本项目的实现选择。

## 1. 调研范围与证据边界

本轮重点不是复刻某个在线产品的外观，而是验证六类高频编辑动作的成熟交互：移动与吸附、显式对齐、页面背景、图表配置、画布缩放、直接文字编辑。Canva 官方帮助中心是主要产品行为证据；开源编辑器架构与打印路线的系统比较继续见 `docs/open-source-research.md`。

已核验的 Canva 官方资料：

- [Moving elements](https://www.canva.com/help/moving-elements/)
- [Layer, group, and align elements](https://www.canva.com/help/layer-group-align/)
- [Page view settings](https://www.canva.com/help/page-view-settings/)
- [Adding backgrounds](https://www.canva.com/help/add-background/)
- [Charts](https://www.canva.com/help/charts/)

## 2. 对齐与吸附

### 已验证的产品行为

Canva 将移动时的辅助线、菜单中的显式对齐、图层/分组操作分开呈现。单个对象可以相对页面定位；多个对象的对齐和分布以当前选择为操作对象。页面视图设置另行提供标尺、参考线和边距，这些精确工具不与拖拽吸附混为同一开关。

### 本项目的实现选择

- 拖拽吸附使用屏幕空间 8 px 阈值，再按当前缩放换算成 mm；50% 与 200% 下的手感保持一致。
- 单选执行左、水平居中、右、顶、垂直居中、底对齐时，以整张页面为基准。
- 多选执行上述命令时，以所选未锁定元素的包围盒为基准。
- 三个及以上元素可执行水平或垂直等间距分布；首尾对象保持在原包围盒边界上。
- 拖拽时的红色辅助线坐标就是最终写入几何所使用的目标坐标，避免“线看似对齐、放手后却不齐”。
- 多选拖拽保留选区内各元素相对位置，以整个选区包围盒参与吸附。

这些命令与拖拽吸附相互独立，并各自生成一条可撤销历史。

## 3. 页面背景

### 已验证的产品行为

Canva 的背景入口与当前页面直接关联；图片可以从浮动工具条或上下文操作设为背景，背景图片可以重新定位。背景不是普通内容图层的同义词，而是页面级能力。

### 本项目的实现选择

- 点击画布空白或页面缩略图后，右侧直接打开“页面”页签。
- 每一种页面类型都能设置背景图，而不再只对封面、章节页和尾页显示入口。
- 章节页使用顶部 70 mm 图片槽；其他页面类型使用整页图片槽。
- 页面背景记录 `imageAssetId`、焦点与 token 化图片风格；Blob 仍存 IndexedDB，不进入历史快照。
- 背景与自由图片可以双向转换。背景永远位于最底层，不参加图层列表、拖拽、缩放和吸附。
- 焦点选择、叠色、渐变、混合、调色预设与暗角均在页面页签完成，编辑态与打印态调用同一图片渲染组件。

## 4. 任意可见对象的编辑边界

页眉机构、页眉章节、页眉线、页脚线、密级、页码以及尾页制度文字全部建模为普通 `ReportElement`。因此它们与标题、正文、图表和分隔线一样可以被选择、移动、缩放、锁定、隐藏、调整层级、对齐并撤销。页面背景仍是唯一的页面级例外，因为它需要保持最底层且不参加吸附。

这里的“可编辑”按内容类型区分：文本元素可双击进入原生输入控件；图表数据、图片、样式与数字走属性面板；分隔线通过选择框和样式面板编辑。图表内部标签不在画布上直接改写，以维持结构化数据与打印确定性。

## 5. 稳定文本编辑

本项目没有采用 `contenteditable`。纯文本与数字使用几何重合的原生 `input/textarea`，因此输入内容、光标、中文输入法组合状态和选择区由浏览器原生控件负责。

只有当内容确实含有局部粗体或语义色 runs 时，才使用透明输入控件叠加只读 runs 镜像；普通 KPI 数字和普通文本直接显示原生控件文字。这一分支修复了“大号数字进入编辑后视觉消失，但 DOM 数据仍存在”的层叠问题。IME 组合期间不提交、不触发快捷键；整次页内编辑在退出时只形成一条历史。

## 6. 图表

### 已验证的产品行为

Canva 的图表通过侧边数据与自定义面板配置，官方帮助页展示了多种图表类型及数据编辑入口。其具体内部渲染实现不属于公开帮助页能证明的范围，因此本文不推断其技术栈。

### 本项目的实现选择

柱线组合图继续复用离线打包的 ECharts，不引入外部运行时资源。每个系列保存：

- `kind`: `bar` 或 `line`
- `axis`: `left` 或 `right`
- `unit`: 轴单位

粘贴 TSV 更新类目与数值时，按系列索引保留上述配置。组合图可同时显示左右数值轴，打印前关闭动画并同步 resize，避免捕获中间帧。

## 7. 缩放

### 已验证的产品行为

Canva 的页面视图设置把缩放比例与页面视图控制放在持续可见的位置，并提供快捷方式；标尺、参考线和边距属于独立的精确视图能力。

### 本项目的实现选择

- 顶栏保留 50%–200%、5% 步进的滑杆和按钮。
- `Ctrl/Cmd + 滚轮` 在画布滚动容器内缩放，并阻止浏览器页面缩放。
- 缩放前记录鼠标对应的页面 mm 坐标，React 完成重排后反向调整滚动量，使该页面点继续停在鼠标下方。
- 缩放值仅属于编辑器 UI 状态，不进入 `ReportDocument`，不会影响打印几何。

## 8. 未采用的做法

- 不把选择框、辅助线、缩放和面板状态写入工程 JSON。
- 不用任意 hex、自由字号或 HTML 字符串保存文字样式。
- 不把页眉页脚保留为渲染器内的特殊 DOM；否则用户无法用统一的图层和几何系统编辑它们。
- 不依据外部产品截图猜测其私有实现，也不把产品帮助页没有说明的内部技术方案写成事实。
