# Local Report Studio v1.7.0 特性基线

状态：`release-candidate`  
应用版本：`1.7.0`  
工程格式：`ReportDocument 1.5`  
固化日期：`2026-08-16`

## 本版目标

v1.7.0 把特化生成器固定为独立模板路径：智能体搭初版，用户在完整编辑器中继续修改；每个图表和表格自己拥有数据，没有跨图关系或勾稽。旧 `bound` 模式只保留为既有报告包兼容能力。

## 用户可见能力

| 领域 | v1.7.0 基线 |
| --- | --- |
| 独立模板 | 打开单 HTML 即进入完整工作台；没有集中“本地数据”栏或布局精修中间页 |
| 局部数据 | 图表与表格组件旁均有“编辑数据”；按提示词预建单元格网格，可逐格修改、增删行列或从 Excel 当前格粘贴连续区域；一次应用只提交当前元素 |
| 完整编辑 | 报告信息、文字、图片、图表、表格、标签、页面、组件、样式、图层均可继续修改 |
| 持久化 | 按报告包 ID 保存完整 `ReportDocument`；资产使用独立命名空间；刷新后恢复 |
| 恢复 | “恢复智能体模板”清除当前独立文档和该包图片命名空间，再载入作者初版 |
| 模式保护 | independent 在验证器层拒绝集中字段、数据版本、派生、规则、录入分区、迁移和三类绑定 |
| 兼容 | 未声明模式的旧包继续按 bound；只做加载/维护/回归，不用于新建报告 |
| 页面 | 混合横竖 A4、动态页数；浏览器实测 15 页和 20 页保存及打印层同步 |
| 隐私 | 单 HTML、CSP、零外部资源；完整工程导入、去 EXIF/GPS、资产 ID 重映射和原子写入；图片数量/解码像素硬上限与解码前尺寸头检查 |

## 财务参考实现

`report-packages/finance-brief/report-package.json` 是首个 `independent` 参考包。它直接保存 10 页作者元素：KPI 仍是 box + text 组合，图表和表格各自保存直接数据，不包含 fields、derived、rules、inputSections、dataMigrations 或绑定。

旧财务绑定实现已固化为 `scripts/fixtures/bound-finance-*` 测试夹具，只用于证明 bound 引擎没有退化，不再作为用户打开的默认特化生成器。

## 已验证

- 内核正反例同时覆盖 independent 和 bound。
- 真实浏览器中修改一个图表不会改变另一图表；修改收入表不会改变相邻圆环图。
- 图表和表格数据、直接编辑文字在刷新后保留。
- 图表和表格不再以原始制表符文本作为常规编辑界面；右侧面板只显示当前对象的数据规模与单元格入口。
- 390 px 下页面栏与属性栏互斥，未见重叠。
- 交替新增纵横页面至 15 页和 20 页后，当前文档、刷新结果与打印层页数一致。
- `test:dynamic-pages` 可重放 20 页交替纵横的编译、单 HTML、真实 PDF 与逐页 A4/方向检查；20 不是固定上限。
- `test:cell-grid` 在真实 Chrome 中通过逐格编辑、增删行列、Excel 区域粘贴、非法值、取消、两次应用两次撤销、图表隔离、稳定 ID 重排、表格草稿及 390 px 内部滚动。

十页参考 PDF 仍需在最终发布门禁中重新生成并逐页检查；15/20 页浏览器编辑与打印层同步及 20 页轻量 PDF 已验证，不等同于完成 20 页复杂图片报告的内存压力承诺。
