# Local Report Studio v1.8.0 特性基线

状态：`release-candidate`
应用版本：`1.8.0`
工程格式：`ReportDocument 1.5`
固化日期：`2026-08-16`

## 本版目标

v1.8.0 把“先套一个专业起点，再逐元素微调”固化为正式能力。模板不是整页截图或不可拆母版，而是一次操作生成普通 `text/box/divider/image` 元素；用户仍可直接改字、换图、移动蒙版、调整 Logo 和规则线。v1.7.0 的 independent 组件数据、完整文档保存、局部单元格编辑和 bound 兼容边界继续保持。

## 用户可见基线

| 领域 | v1.8.0 基线 |
| --- | --- |
| 模板入口 | 左侧固定“页面 / 组件 / 模板”三栏；模板库不占用高级属性面板 |
| 封面模板 | `cinematic-fullbleed`、`editorial-monogram`、`institutional-rail`、`split-image-panel`、`publication-window` 共 5 套 |
| 横竖适配 | 每套模板分别维护 portrait 与 landscape 几何，不用比例缩放冒充适配 |
| 封面微调 | 图片、蒙版、Logo、标题、副标题、报告期、编制部门、密级和装饰线均为独立元素 |
| 页眉页脚 | `minimal-rule`、`brand-rail`、`editorial-corner` 共 3 套；适用于章节页、标准页和数据页 |
| 内容保护 | 切换页眉页脚只替换制度元素，不删除正文、图表或表格；切换封面保留标题、副标题和当前图片 |
| 历史 | 应用一次模板只形成一条文档撤销记录；无需二次确认即可快速试版 |
| 品牌资源 | 透明彩色 PNG、透明白色 PNG、项目横向组合 PNG；5 张本地可再分发航运起始图 |
| 编译 | 报告包含显式 `chrome-template:*` 元素时，内核不再叠加默认页眉页脚 |
| 参考包 | 财务简报保持 10 页 independent 独立组件数据，封面升级为影像模板，内容页统一品牌侧轨 |

## 不变边界

- 新建特化报告继续只使用 `authoringMode: "independent"`；每个图表和表格维护自己的数据。
- 模板输出只允许 `text/box/divider/image/chart/table` 六种原子元素，不增加 `cover-card`、`header` 或 `kpi` 等持久化类型。
- 主题颜色、字号和字体继续使用 token 与白名单；模板不写任意 CSS 或 HTML。
- 内核只要求至少一页，不设置最大页数。10 页只是财务参考包当前页数。
- 运行时不包含 CDN、远程字体、图片热链、遥测、登录或云上传。
- 项目主题和横向组合标识不代表正式公司品牌手册；商标与第三方素材权利边界单独说明。

## 验收面

1. `test:templates` 对 5×2 套封面和 3×2 套页眉页脚逐项验证边界、原子性、可编辑性、母版图片/裁切保留、实际资产安装，以及页面增删和设置变化后的机构、章节、密级、页码同步。
2. `check:brand-assets` 验证三个 Logo PNG 的文件签名、RGBA、透明四角、尺寸、字节数与 SHA-256，并验证五张 JPEG 起始图。
3. 真实浏览器验证模板切换、一次撤销、标题/图片保留、内容页图表不变、390×844 面板无文档级溢出。
4. `qa:templates` 生成 16 页真实打印矩阵，覆盖全部封面和页眉页脚的横竖版，逐页核对 A4 方向、可搜索文字与异常空白，并输出总览图。
5. 完整发布门禁继续生成财务参考 PDF、做字节确定性检查并逐页核对 A4 方向和渲染图。
