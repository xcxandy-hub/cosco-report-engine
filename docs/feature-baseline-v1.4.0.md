# Local Report Studio v1.4.0 特性基线

状态：`frozen-baseline`  
应用版本：`1.4.0`  
工程格式：`ReportDocument 1.4`  
固化日期：`2026-08-15`

本文定义 v1.4.0 已交付的功能边界。规范性行为以 [v1.4.0 契约](./contracts-v1.4.0.md) 为准，机器可读版本位于 [`release/v1.4.0.json`](../release/v1.4.0.json)。v1.3.0 基线继续保留，只作为历史发布证据。

## 1. 本版目标

v1.4.0 把“视觉模块”和“持久化元素”分开：用户仍可一键插入 KPI、重点结论、趋势图组和表格模块，但工程只保存可复用的基础元素。这样 KPI 数值、单位、标签、背景和说明可以分别编辑、重新组合或拆组，不再由专用组件限制。

## 3. 元素化边界

- KPI 由一个 `box` 和四个 `text` 组成；没有 `type: "kpi"`。
- 重点结论由背景、引号、正文和署名组成；没有 `type: "quote"`。
- 页面标题、来源和图题都是 `text`，差异由 `semanticRole` 表达。
- 四种图表共享 `type: "chart"` 和结构化数据，差异由 `chartKind` 表达。
- 图表与表格仍是基础元素，因为它们有独立结构化数据、渲染器和属性面板；不拆成绘图原语。

## 4. 兼容与迁移

- 读取支持 1.0、1.1、1.2、1.3 和 1.4；运行态与导出固定为 1.4。
- 1.3 的 title/source/kpi/quote、四种图表类型和表格/图表内嵌标题会展开为 1.4 原子元素。
- `value/unit/note` 只允许作为旧工程迁移输入，1.4 工程不写入。
- `npm run test:migration` 检查 1.3 展开、1.4 二次导入稳定和 1.0 制度元素补齐。

## 5. 研究出版模板

模板包含封面、导读、章节、核心洞察、数据图谱和尾页。它把机构样本中可泛化的章节节奏、窄叙事栏加主图、独立图题/来源、稳定密集网格转为本项目自有布局，不复制任何机构标志或专有模板。

## 6. 明确不在范围内

- 组合比例缩放、旋转、嵌套组合和跨页组合。
- 云模板、多人协作、账号、遥测、在线素材和远程数据源。
- Word 式连续长文、自动目录、跨页长表和脚注续排。
- 直接生成 PDF 字节流、内嵌未授权商业字体或复制机构品牌资产。

组合缩放未实现不是遗漏：文字组合若任意比例缩放，会把字号和行高写成白名单外数值。v1.4.0 允许整体移动和拆组后逐项调整，后续需要基于布局约束而不是纯几何比例另行设计。
